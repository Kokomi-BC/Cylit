# 论文精读

## 什么时候用

- 「帮我精读 / 读懂这篇论文」「它到底做了什么」。
- 「这个结论成立吗」「局限在哪」「审稿人会挑什么毛病」。
- 「我能从这里借什么」：选题、实验设计、写作、可视化。
- 「这篇值不值得读」—— 走下面的「快判」，不要上完整流程。

不属于这里的事：某处细节怎么讲 → `read-text` / `read-formula` / `read-figure`；
跨段落取证式问答 → `answer-paper`；只要「讲了什么」的四百字概览 → 直接按概览答。

## 两条路，先选一条

**快判（五分钟）**：只给一页结论卡 —— 一句话定位、Research Gap、科学问题、核心方法、
不超过三条核心发现、关键图表、创新点、最大局限、阅读价值与建议。用户没说「完整精读」时默认这条。

**完整精读**：走完下面九步。

## 硬规则（比流程更重要）

1. **证据优先**：核心数值、创新点、结论、机制解释，每一处都要能指回论文位置。
2. **不编造**：原文没明说的写「原文未明确报告」，不要为了把模板填满而补。
3. **不猜数值**：图里读不准的具体数字不目测；写「趋势可见，精确值无法可靠读取」。
4. **来源分层**：`[原文事实]` / `[作者解释]` / `[模型推断]` / `[待验证假说]` 四档分开写，
   推断不许冒充事实。
5. **结论强度跟着证据走**：相关性不写成因果，proxy 不写成直接测量，仿真不写成实验验证。
6. **定位统一**：`PDF p.X` / `Section` / `Fig. X` / `Table X` / `Eq. X`；印刷页码与 PDF 页码
   不一致时以 PDF 页码为准，并在第一次出现时说一句。
7. **方法与目的绑定**：不只罗列「用了什么方法」，每个方法都要写一行「它在证据链里负责验证什么」。
8. **缺失透明**：正文依赖的补充材料没拿到，就列出因此无法验证的结论，不装作读全了。
9. **不逐段翻译**：目标是重构科研逻辑，不是把 Abstract / Introduction 换个说法。

## 流程

### 第 0 步 · 边界与类型

先判断这是实验、计算与模拟、生信、临床与观察、方法学还是综述，再决定看什么
（路线见下面「按类型换路线」）。同时说清边界：只有摘要、PDF 缺页、图糊、补充材料缺失，
这些都要先讲，再继续能可靠做的部分。

### 第 1 步 · 身份与一句话定位

标题、作者与单位、期刊与年份、DOI、关键词、文章类型 —— 只填原文里有的。
期刊分区、影响因子这类外部指标**不许凭记忆写**：原文没有就说「需外部数据库核验」，不要编一个数字出来。

一句话定位的句式：**对象 + 方法或干预 + 要回答的问题 + 最关键的结果**。

### 第 2 步 · 三十秒判断

研究问题 / Research Gap / 核心方法 / 核心发现（一至三条）/ 核心创新 / 最大局限 /
阅读价值（一至五星）/ 阅读建议（精读、重点读、泛读）/ 建议先读哪一节哪张图。

### 第 3 步 · 重构研究故事（不要顺着段落复述）

`背景 → 已有工作 → 真正的缺口 → 科学问题 → 假设（若有）→ 研究目标 → 设计 → 证据 → 结论 → 意义`。
这条链上每一环都要回答「为什么这一步必须存在」：为什么这件事值得做、前人卡在哪、
作者用什么换来了突破、哪条证据把逻辑闭合了。

### 第 4 步 · 方法学拆解

按类型取需要的项：研究设计、对象与材料与样本与数据集、变量与控制、对照或基线、
实验或计算流程、关键条件与参数、仪器与软件与模型、统计方法、样本量与重复、误差与显著性、
验证策略、可重复性信息。

两个必答项：

- 每个关键方法：**它在证据链里负责验证什么？**
- **若我要复现，正文还缺哪些必要信息？**

### 第 5 步 · 证据卡（一个核心结果一张）

不要写「结果 1 / 2 / 3」。每张卡：科学子问题、主张（Claim）、直接证据、关键数值或统计量、
对照或比较对象、原文位置、作者解释、证据强度（强 / 中 / 弱）与理由、
**这条证据能证明什么**、**不能证明什么**。几张卡由论文决定，不凑数。

### 第 6 步 · 关键图深读

只深读支撑核心结论的图，不逐张复述。每张回答：它回答哪个问题、横纵轴与分组与图例各是什么、
对照是什么、最重要的趋势、能可靠读出的数、误差与显著性怎么表达、支撑哪条主张、
有没有另一种解释、这张图不能支持什么。

最后回答一句：**「如果只能保留三张图，留哪三张、为什么？」**
图里读不准的数回到正文或表里找，找不到就说图里没有（取图交给 `read-figure`）。

### 第 7 步 · 机制

`现象 → 直接证据 → 作者解释 → 可能机制 → 缺失验证`，四层标签照硬规则第 4 条标。
论文只证到相关关系时，机制只能写成推断或假说，不能写成结论。

### 第 8 步 · 审稿人视角

创新点是否成立、主张与证据是否匹配、方法能不能回答这个问题、对照够不够、
样本量与统计是否站得住、有没有混杂、有没有过度外推、作者自己承认了哪些局限、
作者没提但确实存在的问题。

收尾一句：**「如果我是审稿人，最希望作者补的三项实验 / 分析 / 验证是什么？」**
每项都要说清它排除哪个替代解释、补齐哪条证据链 —— 不要泛泛地要「更多实验」。

### 第 9 步 · 科研复用

用户给了课题就贴着课题写；没给就写通用复用：可放进 Introduction 与 Discussion 的论点、
可借鉴的方法与流程、可参考的参数或实验设计（仅原文明确时）、值得学的图表结构、
可学的表达（短语句式，不大段照抄）、值得追的参考文献、可延伸的缺口与可形成的新问题。
「能引用」不等于「可复制」，写作时仍要回原文核对。

## 按类型换路线

- **实验类**：自变量、因变量、对照、重复与误差是一等公民，先看设计再看结果。
- **计算与模拟**：模型假设、数据集与划分、基线选择、消融、计算预算；外推到真实数据前先问假设是否成立。
- **生信**：数据来源与预处理、批次效应、多重检验校正、验证集是否独立。
- **临床与观察**：入排标准、终点定义、随访时长、混杂控制、效应量与置信区间；观察性研究不谈因果。
- **方法学**：与最强基线的比较是否公平、收益从哪来（消融能否解释）、适用边界在哪。
- **综述**：不套自变量与因变量，改看检索与纳入逻辑、证据范围、主题分类、争议点与未解决问题。

## 输出形态（写在回答里，不写文件）

按需要给三段，段内用上面的字段，不要套模板标题大赛：

1. **一页结论卡** —— 快判与完整精读都给。
2. **精读正文** —— 第 3 至 9 步的内容，按「故事 → 方法 → 证据 → 机制 → 批判 → 复用」排。
3. **证据索引** —— 主张 / 证据 / 位置三列的对照表，一条主张一行。

再需要时补一段「待确认信息」：缺页、缺补充材料、读不准的图、要外部数据库才能核实的指标。

## 说话方式

中文解释，关键英文术语原样保留；先讲为什么，再讲是什么；结论尽量用「结论 + 证据 + 定位」三件套。
语气克制，不用「显著提升 / 显著降低」这类统计词，除非论文真的报了统计显著性。
不把作者的措辞当成事实，关键主张一律回到数据。

## 异常处理

- **PDF 缺页或扫描糊**：点明受影响的页与图，并说明哪条结论因此打折。
- **补充材料缺失**：列出正文依赖它、但无法验证的部分。
- **一次给多篇**：除非用户明确要批量，否则先做一篇；要多篇就各自建证据卡再横向比较，不同论文的证据不许混着说。
- **用户只想判断值不值得读**：走快判，不要输出完整长篇。
