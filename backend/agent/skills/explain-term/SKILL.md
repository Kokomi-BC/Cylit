# 术语与译法

## 什么时候用

- "QJL 是什么的缩写？"
- "random rotation 这篇里译成什么？"
- "帮我列一下这篇论文的关键术语"
- "这两个词是同一个东西吗？"

## 流程

1. **档案里的“统一译法”“保持英文不译”两段是现成的**：先看它，那里是**全文统一的口径**
   （翻译流程用的就是它）。答案能对上就直接用，不要另起一套译法。
2. 档案里没有该术语时，`paper_search` 找它**在文中第一次出现的定义句**
   （缩写通常在摘要或引言里展开）。用户一次问好几个术语就**一次给几个词**：
   `paper_search(queries=["QJL", "random rotation"])` —— 回执按词分组，别一个词一来回。
3. 想看它在译文里的实际说法，用 `translate_get(pages)` 取那几页的中文，
   或 `page_markdown_get`（一次给原文 + 译文，便于对照）。
4. 回答格式：`英文原词（缩写全称）→ 中文译法 —— 一句话说明它在这篇论文里指什么`。

## 硬要求

- **区分"业界通用译法"与"这篇论文的用法"**。用户问的是后者；前者只在明显需要时补一句。
- 缩写展开必须来自论文本身，不要按你记忆里的写法填（同名缩写在不同领域含义完全不同）。
- 译法**以档案的「统一译法」那一段为准**，即使用户习惯别的译法：回答里可以提一句"本文统一译作 X"。
- 不要为了凑数罗列一堆普通词（"model→模型"这种没有信息量）。
