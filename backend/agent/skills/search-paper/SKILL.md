# 论文检索

## 两个工具，先分清范围

- `paper_search(query, top_k, mode)` —— **只在当前这一篇**里找。问「这篇怎么写的 / 为什么这么做 / 实验数字多少」都用它。
- `kb_search(query, top_k)` —— 在**整个知识库**里找，结果会带 `paper_id` 与页码。问「我库里还有谁讲过这个 / 有没有别的论文提到 X」才用它。

**不要用 `kb_search` 回答「这篇论文怎么说的」**：那属于 `paper_search`，跨库检索会把别的论文的片段混进来。

## 批量：一次给几条，别一条一来回

- **几个词一起查**：`paper_search(queries=["随机旋转", "量化误差"])` /
  `kb_search(queries=[…])` —— 回执**按 query 分组**（`groups`），不同词的命中不会混成一个数组；
- **几个 ref 一起展开**：`block_get(refs=[3, 5, 9])` —— 回执逐条对应，某条失败只在那条上给原因；
- 上限：一次最多 **8 个词 / 12 个 ref**；超了会截断，并在回执里写明「还有 N 条没处理」。

## 写法：后端已经归一过，但换写法常常还是有用

查询前有两件确定性归一（不是猜，也不靠你背规则）：

- **下标 / 下划线**：`TURBOQUANT_mse`、`TurboQuant$_{mse}$`、`TurboQuant MSE` 归一到同一批块 ——
  下划线被当分隔符拆词。实测这条以前是**词法 0 条**（正文写作 `TURBOQUANT$_{\text{mse}}$`，
  查询却成了整 token `turboquant_mse`），所以带下标的名字不要再自己改写成奇怪的样子，照写就行；
- **缩写 ↔ 全称**：正文里出现过 `全称 (缩写)` 或 `缩写 (全称)` 句式，查任一侧都会带上另一侧
  （`SLB` ↔ `Shannon lower bound`，实测两组结果以前只重叠一半）。所以同一个概念**不必查两遍**。

**仍然值得换写法的情况**：正文里根本没有那种句式 —— 用户自造的译名、中文口语词、缩写从未展开过。
这时该换的不是同义词，而是**换语言**（中文问就查 zh 行）或换 `rag`。

## 检索方式怎么选（`mode`，只对 paper_search 有）

**后端不会按语法替你自动切换**：`auto` 只是「两路都跑」，不是「替你想好了」。这一次走哪条路，**由你**，
依据是**这一句查询长什么样**（不是论文长什么样）：

| 查询长什么样 | 用哪个 `mode` |
| --- | --- |
| 带编号的物件：`Algorithm 2`、`Theorem 3`、`Lemma 2`、`式 (7)`、引文编号 `[13]` | `text` |
| `$…$` / `$$…$$` 公式片段、指标名（`MSE`、`recall@10`）、专有名词、方法名、缩写 | `text` |
| 带下划线/下标的写法（`TurboQuant_mse`）—— 拆词后词法最准 | `text` |
| 用户给了引号的原文、要「一字不差地找这句话」 | `text` |
| 整句自然语言、同义说法、跨语言（中文问英文论文） | `rag` |
| **判断不了**，或第一次探路 | `auto` |

选完看回执里的 `select`：它写的是这次**实际**跑了哪一路 —— 没跑对就换一种再来一次，别在同一路上反复改词。

片段是**以命中处为中心**截的：如果下发的片段里找不到你的查询词，说明命中的是邻词、不是你要的那句，
换词比加大 `top_k` 有效。

## 检索只给位置，不给正文

拿到结果里的 `ref` 之后：

1. 先用 `block_get(refs=[…])` **一次**展开最相关的那几块 —— 那才是相似内容本体，也是唯一能直接引用的文本；
2. 块里上下文不够，再 `page_markdown_get(pages)` 读它所在的整页（需要看版面才 `page_image_get`）。

引用规则不变：回答里只写**已经被读出来的块**的编号，不要把检索片段当正文引用。

## 零命中的排查顺序（别只换同义词）

1. 先看**写法**：下标拆开、术语换回正文里的英文原词（译文里的术语常和原文对不上，只查一面会少一半素材）；
2. 再换 `text` ↔ `rag`：精确词没中就换 `text`，概念没中就换 `rag`；
3. 仍是「同一概念两种写法、各搜到一半」（`SLB` / `Shannon lower bound`、`TurboQuant_mse` /
   `TurboQuant MSE`）→ 用 `term_manage(op="add")` **登记一条检索变体**，之后两种写法查到同一批块。
   一次可以给几组；它只改检索，**不改译法**，写错了 `op="remove"` 就能撤。判好坏看回执里的
   `gained`（多带回了哪几页），不要看条数；
4. 还空 → 大概率这篇**真的没有**：直接说「本文未检索到」，不要拿相邻段落硬凑，也不要凭记忆补。

## 跨库检索的边界

`kb_search` 返回的片段来自别的论文时，**你并没有读过那篇**：只能按片段说明"某篇提到了 X"，
并给出 `paper_id` / 页码让用户自己去看。不要复述细节、不要编造它的结论。

## 和别的技能的分工

- 要读全文 / 读整页 → `read-text`；
- 要解释图、表、公式 → `read-figure` / `read-formula`；
- 要查公开网页（不是本地库）→ `web-search`；
- 要给整篇概览、或按精读流程带你读一遍 → `deep-read-paper`；
- 术语"怎么译" → `explain-term`。
