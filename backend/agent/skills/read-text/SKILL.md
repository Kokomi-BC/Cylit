# 按页读取论文正文

本技能负责按页读取论文正文，每次最多 5 页，不连续页码可以合并请求。
- 双语对照： 使用 page_markdown_get(pages) 获取原文与译文两侧内容。
- 英文原文： 使用 page_markdown_get(pages)，读取返回结果中的原文侧。
- 中文译文： 使用 translate_get(pages) 获取译文。
整理返回结果时，保留工具提供的证据编号，按照论文原有叙述顺序组织内容，而非机械罗列文本块。公式附近的常数或可能受解析影响的信息，必要时核对原版面。

## 按页

`pages` 的写法：单页 `"5"`、区间 `"3-8"`、多页 `"4,7"`、整篇 `"all"`（`p4` / `第 4 页` 也认）。

**一次别超过 5 页**：多了上下文会被挤掉，读者想要的细节反而漏掉；按需再取下一段。

**但要读的页不连续时，一次给完**：`page_markdown_get(pages="1,3,8")`、`translate_get(pages="4,7")`
—— `pages` 本来就是"一批页"的写法，别一页一次调。手上的 ref 有好几个时同理：
`block_get(refs=[…])` 一次展开，回执逐条对应。
（工具本身允许到 20 页，但那不是"一次该读多少"的理由。）

## 读出来以后

**连续复述**，按叙述走，不要按块走：

- 这一节在讲什么（问题与背景）；
- 论证怎么推进（先做了什么、为什么、接着又做了什么）；
- 得出了什么结论、有没有前提条件。

不要逐句翻译，也不要逐块罗列（"第 1 块说……第 2 块说……"等于把读模型原样搬给用户）。

## 硬要求

- 公式、符号、引用编号、图表编号**原样保留**：别把 `$d_k$` 写成 d k，别丢 `[12]`，
  别把 `Figure 3` 说成"那张图"。
- **要写进回答的常数 / 数值 / 上下标，先对页面图**（`page_image_get`）。转录里的 LaTeX 不可靠：
  `\sqrt{3}\,\pi^2` 与 `\sqrt{3\pi^2}` 在转录里会是**同一串字符**（根号覆盖到哪儿的信息丢了），
  抄错一个常数就把结论写反。凡是会改变结论的符号都先看原版面；只做概念性说明时才只凭转录。
- 读到明显的漏译 / 错译：**只标注一句**（哪一页哪一句看起来不对），然后继续读正文 ——
  这一步不负责整篇逐句挑错（读正文和核对译文是两件事，混在一起两头都做不实）。
- **页边界两侧长短不一不是错**：英文是**按页切**的转录，句子在页尾被切断很常见；
  中文译文是逐页翻译时带了上一页的结转，所以**那一句往往是完整的**。看到"英文停在半句、
  中文是整句"，先去看**下一页开头**接不接得上，接得上就是正常现象，别当成漏译/错译报给用户。
- 引用要给 ref：`page_markdown_get` 与 `translate_get` 回来的都是带编号的块，复述里
  支撑论断的句子带上那个编号。
- 若手上的 ref 来自检索（`paper_search`）而 `block_get(refs=[…])` 展开失败 —— 附录页实测会失败，
  当常见情况处理：改用 `page_markdown_get` 读**那一页**，从页级结果里取新的 ref 再引用。
