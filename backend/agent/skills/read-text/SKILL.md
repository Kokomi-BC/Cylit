# 读论文正文

## 选读哪一份

- **英文原文** → `page_markdown_get(pages)`（返回里的原文侧就是英文转录，逐块带 ref）；
- **中文译文** → `translate_get(pages)`（只回译文、逐块带 ref）；
- **两者对照** → `page_markdown_get(pages)`：它默认一次给两侧，不用取两次。

用户没说读哪一份时，**默认用 `page_markdown_get(pages)`**（一次给原文 + 译文两侧，不用取两次）；
只有用户明确只要中文译文时，才用 `translate_get(pages)`。中英两路是两套读模型
（A 路转录 / B 路译文），要对照就看同一份返回里的两侧，不要分别取两次。

## 按页

`pages` 的写法：单页 `"5"`、区间 `"3-8"`、整篇 `"all"`。

**一次别超过 5 页**：多了上下文会被挤掉，读者想要的细节反而漏掉；按需再取下一段。
（工具本身允许到 20 页，但那不是"一次该读多少"的理由。）

## 读出来以后

**连续复述**，按叙述走，不要按块走：

- 这一节在讲什么（问题与背景）；
- 论证怎么推进（先做了什么、为什么、接着又做了什么）；
- 得出了什么结论、有没有前提条件。

不要逐句翻译，也不要逐块罗列（"第 1 块说……第 2 块说……"等于把读模型原样搬给用户）。

## 硬要求

- 公式、符号、引用编号、图表编号**原样保留**：别把 `$d_k$` 写成 d k，别丢 `[12]`，
  别把 `Figure 3` 说成"那张图"。
- 读到明显的漏译 / 错译：**只标注一句**（哪一页哪一句看起来不对），然后继续读正文 ——
  系统性挑漏译是 `check-translation` 的活。
- 引用要给 ref：`page_markdown_get` 与 `translate_get` 回来的都是带编号的块，复述里
  支撑论断的句子带上那个编号。
- 若手上的 ref 来自检索（`paper_search`）而 `block_get(ref)` 展开失败 —— 附录页实测会失败，
  当常见情况处理：改用 `page_markdown_get` 读**那一页**，从页级结果里取新的 ref 再引用。
