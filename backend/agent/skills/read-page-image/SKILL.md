# 核验论文页面原图

本技能负责查看论文页面原图，核对版式、公式分式与上下标、表格结构和图中标注等视觉信息。先确定需要检查的页码，每次最多读取 3 页。普通文字优先使用文本层，只有需要核验排版或补充视觉信息时才读取原图。检查结果用于确认解析是否准确，不直接修改英文转录或中文译文；需要修改时交给 edit-text。

## 什么时候用

- 要讲清楚一个公式的**排版含义**（分式、求和范围、上下标）；
- 表格的行列、数字对齐需要眼见为实 —— 但**表格优先走 `figure_list` 找到表、再 `figure_image_get` 看表图**
  （更清楚也更便宜）；整页图留给版式与上下文；
- 图里的标注、图例、坐标轴在正文里没提到；
- 若文本与原文对不上（乱码、公式缺项、上下标错位、数字串位），也走这一套核对。

## 流程

1. 先用 `paper_search` 或 `page_markdown_get` 找到出问题的是哪一页。
2. `page_image_get(pages="5", dpi=300)` 看原版面（`pages` 也可以写区间 `"3-5"`）。**公式密集的页给 300~400**，
   默认 200 只够读普通正文。
3. 对照着说：文本层给的是什么、原版面实际是什么。
4. 如果确认解析有误，**如实说明**，不要用"应该是……"把错误圆回去；
   修正文本走 `edit-text`，你在这里只需要指出问题。

## 硬要求

- **不要放大低 dpi 图来代替高 dpi**：放大只是插值，信息量没变。要看清就重新取图。
- 一次最多看 3 页，别把整篇论文当图片读 —— 文字信息用 `page_markdown_get` 更准也更便宜。
- **要核对的页面 / 区域不止一个时，一次给完**：整页用 `page_image_get(pages="3,5,7")`（上限 3 页），
  区域裁图用 `figure_image_get(items=[{"page": 4, "index": 1}, …])`（上限 6 个）。
- 公式的 LaTeX 以**文本层**为准来引用（那才是能被检索到的版本），版面图只用来核对。
- 中文译文与原文公式不一致时，报告不一致并给出原文版本。
