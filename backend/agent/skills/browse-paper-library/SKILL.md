# 浏览论文目录

## 先分清三种问法

| 用户说的话 | 这是哪种查询 | 怎么调 `library_list` |
| --- | --- | --- |
| 「有哪些分类 / 每个分类几篇」「XX 分类里有什么」 | 分类查询 | 先不带 `query`，直接看回执的 `categories`；要列某个分类的论文就 `folder=<分类 id>` |
| 「我库里有什么论文」「列一下书架」 | 论文列表 | 不带 `query`、不带 `folder`，给第一页 |
| 「有没有讲 XX 的论文」「关于 XX 的文章」 | 关键词搜索 | `query="XX"`（标题与作者模糊匹配） |

- 分类 id 从回执的 `categories` 里取（`id` / `name` / `paper_count`）；`folder="none"` 是**未分类**那一批。
- 关键词和分类可以同时给：`query="量化"` + `folder=<id>` = 在这个分类里搜这个词。
- 用户问「这个分类里有什么」时别自己编关键词，把 `folder` 传进去就够了。

## 怎么调

```python
library_list(query="量化误差", folder="folder-xxx", status="parsed", page=1, page_size=20)
```

- `page` 从 1 开始；`page_size` 默认 20、上限 50。
- `in_kb` 默认 `true`：**只列已入库的论文**；要看未入库的那批传 `in_kb=false`（见下一节）。
- 这一页在 `items`；位置与总量在 `page` / `page_size` / `total` / `total_pages` /
  `has_next` / `has_prev`，外加一句现成的 `page_info`（如「第 2/6 页，共 120 篇（每页 20 篇）」）。
- 一条都没有时 `items` 为空、`total` 为 0，并带 `hint`。

## 默认只列已入库的论文

- 默认（`in_kb=true`）**只列已经入库的论文**（`in_knowledge_base=1`，也就是真的能被检索到的那批）；
  回执的 `scope` 写明这次的口径：`in_knowledge_base` / `not_in_knowledge_base` / `all`。
- 回执里的 `hidden_not_in_kb` 就是**没列出来的那一批**：同一批条件（`query` / `status` / `folder`）下
  有多少篇匹配但**未入库**。它的值**不在** `total` 里，讲数量时要分开说：
  「已入库 N 篇；另外还有 M 篇没入库（这次没列出来）」（N = 这次的 total，M = hidden_not_in_kb）。
  **不要**念成"库里只有 3 篇"，也不要说这几篇被删了 —— 未入库 ≠ 已删除（删论文不回填这个标记）。
- 用户要看那一批（"还没入库的 / 书架里有但知识库里搜不到的"）时，显式传 `in_kb=false`，其余参数照旧；
  那时 `hidden_not_in_kb` 反过来就是"已入库、这次被挡掉"的篇数。
- `categories` 的计数是**全库口径**（回执里 `categories_scope` 固定为 `all_papers`，来自分类服务），
  它**不跟着** `in_kb` 变，也不等于本页 / 本口径的条数 —— 分类计数与 `total` 对不上是正常的，
  别拿一个去纠正另一个：讲「分类里几篇」用 `categories`，讲「这次列了几篇」用 `total`。

## 翻页：照回执里的元数据回应

- 「下一页」→ `page` 取回执里的 `page` **加 1**，其余参数一个都不改；
- 「上一页」→ `page` 减 1；回执里 `page=1`（`has_prev=false`）时直接说"已经是第一页"；
- 「跳到第 N 页」→ 直接把 `page` 设成 N。N 越界时后端会钳到合法页，回执里的 `page` 写的是
  **实际**用的那一页 —— 照它说"这是第 X/Y 页"，不要按你传的 N 宣称；
- `has_next=false` 就说"这是最后一页"，别让用户继续往下点。

## 连续翻页时这三样不要变

- 原搜索词 `query`、分类 `folder`、每页条数 `page_size` 都要**原样带下去**：漏掉任何一个，
  第二页就换成了另一个结果集，用户会看到重复或漏掉的论文；
- 只有用户**主动改条件**（换关键词、换分类、改每页条数）时，`page` 才重置为 **1**；
  条件变了还停在原来的第 5 页，等于给用户看一个空页；
- 换了条件之后如果还有 `has_next`，从第 1 页重新开始数。

## 输出：先摘要，再当前页

- 先一句摘要：「共 120 篇，分 6 页，当前第 2 页」，需要时附上分类计数（「量化 34 篇、未分类 21 篇……」）；
- 回执有 `hidden_not_in_kb`（且大于 0）时补一句：「另有 N 篇未入库，这次没列出来」——
  不说这句，用户会以为库里就这几篇；
- 再列当前页：每条尽量带 `paper_id`（用户下一步读某一篇时，它是唯一的抓手），
  以及标题、作者/年份、`folder_name`、状态；
- **不要一次把整个库倒出来**：只给这一页 + 一句"要看更多我接着翻"，让用户决定往哪看；
- 用户说"全都列出来"时也按页给，一页一页翻，不要拼成一大段。

## 目录只是元数据

- `library_list` 返回的是书架元数据，**不等于你读过那篇论文**；条目里的 `abstract`（若有）
  是截断版（不超过 200 字），不能当作全文结论；
- 要讲某篇的具体内容，必须再用 `kb_search` 或 `block_get` / `page_markdown_get` 取正文；
- 提到别的论文时给出它的 `paper_id`（必要时加页码），别把目录里的标题当成"读过的证据"。
