# 高亮与笔记：`Highlight └── Note`

两件事一起管：**高亮**是"用户在某一面上标出来的一段文字"，**笔记**是挂在某条高亮上的正文。
关系固定 —— 笔记的锚点就是那条高亮，所以**没有孤儿笔记**：要写笔记，先有高亮。

## 什么时候用

- "把第 3 页那段 `Attention Is All You Need` 标成黄色" → `highlight_manage op=create`
- "这段加个笔记：这里其实是……" → 先确认/建立高亮，再 `note_manage op=create`
- "我标过哪些？""这篇的笔记都有什么？" → `op=list`
- "这条笔记对应原文哪里？""跳到那处高亮" → `op=locate`
- "把那处高亮删了""笔记内容改成……" → `op=delete` / `op=update`（**用户明确说了才做**）

**不要**因为"这段话很重要"就自己去标：标注是用户的动作，你只在被要求时做。

## 三面锚点：先说清"标在哪一面"

| `anchor` | 是什么 | 例子 |
|---|---|---|
| 正文行 id | 阅读器里那一行（原文/译文对照的一行） | `p004-02` |
| `md:p<页号>` | Markdown 视图里那一页 | `md:p4` |
| `pdf:p<页号>` | 原 PDF 的页图 | `pdf:p4` |

锚点用 `md:p<页号>`：宿主会把它挪到该页对应的正文行上（见 `annotations.py` 的 `locate_in_rows`），
**不要自己编 `p009-08` 这种行 id** —— `page_markdown_get` / `block_get` 的返回里没有 `row_id`。
**原 PDF 那一面只能查不能建**：它的文字层在阅读器的 pdf.js 里，服务端算不出偏移量 ——
要标那儿就让用户在 PDF 页上自己划词，你负责解释与写笔记。

### 默认标译文面（中文）

用户口径（2026-12-06）：**优先给中文加高亮**。读者平时看的是译文那一列，而高亮只画在它所属的
那一面 —— 标在英文原文面的高亮，用户在中文视图里**根本看不到**（"笔记在列表里、正文一片白"
就是这么来的）。所以：

- **不要显式给 `side`**：宿主按文字自动判（中文 → 译文面；公式 → 译文面）；
- 要给就写 `zh` / `en`（只有这两个是准的；`original` / `translation` 只做归一化，别依赖）；
- 只有用户明确说"我在读英文原文"时，才用 `en` 并且拿英文原文来标。

中文原文从 `translate_get` / `page_markdown_get` 的译文侧拿；别自己补标点或改空格。

### 公式怎么标

公式**可以**直接标（2026-12-06 之前不行，别再用旧结论）：把公式的 LaTeX 原样作为 `text` 给它 ——
带不带 `$$` 都行，只给式子的一部分也认（至少 8 个字符）。坐标系里公式整体只占 1 个占位符，
宿主会把 LaTeX 换成那个位置，前端据此把**整个公式节点**包起来（块级公式连外接框一起）。

```
highlight_manage op=create anchor=p016-17 text="$$D(B) \geq 2^{-2B/d}$$"
```

**不要**因为"公式不是文字"就退回去标引出它的那句话 —— 那样笔记挂在一句旁白上，用户点开看到的
不是公式本身。真找不到时工具会回"最像的原文"，照着 LaTeX 再改一版。

## 配色：多彩、尽量不一样

用户口径（2026-12-06）：**高亮要多彩，尽量每条都不一样**。一片同色等于没有颜色 —— 用户扫一眼
应该能靠颜色分出层次（哪条是术语、哪条是结论、哪条是疑点）。

- 动手前先 `highlight_manage op=list` 看这篇**已经用过哪些颜色**，挑没出现过的、或者用得最少的；
- 一次标好几处 → **逐个换色**，不要整批同一个颜色；
- 更好的做法是按语义分配，全文一致（例如：术语 `violet`、结论/定理 `green`、公式 `blue`、
  疑点/存疑 `orange`、待办 `red`）—— 一致不等于都用同一个色；
- **颜色代码可以自己给**：`#0d9488`、`rgb(20,120,140)`、`hsl(180 60% 40%)` 都会原样存下并画出来；
  常见颜色词（teal / cyan / amber / rose / slate / sky …）也会被认成 hex。想按语义自己设计一套
  配色（术语 teal、结论 emerald、公式 indigo、疑点 amber）就直给色码，不必迁就那七个色名；
- 不传 `color` 时宿主会挑**当前用得最少**的颜色兜底，但别指望它替你表达语义。

## 三条硬规则

1. **`text` 必须逐字一致**。要标的文字照抄工具返回的原文：Markdown 记号**不算字**
   （原文写 `**重点**`，你给 `重点`）、行内换行按排版接回。**公式例外**：给它 LaTeX（见上节）。
   找不到时工具会回"最像的原文"，照着改一版再试 —— 不要瞎猜、也不要自己编偏移量。
2. **写之前先看**。"标这段"要先知道它在哪一面、哪一行（`paper_search` / `page_markdown_get`）；
   "给高亮加笔记"要先 `highlight_manage op=locate` 确认那条高亮是用户说的那一条
   （同一段文字可能出现多次，靠 `occurrence` 区分）。
3. **删除是高危动作**：只在用户明确说"删掉"时做，且必须 `reason` 写清是哪一条；
   删高亮会**连带删掉它挂的笔记**（锚点没了笔记就成了死数据）——做之前说清后果。

## 回答怎么写

标完 / 写完，用一两句话交代**位置**：第几页、哪一面、标的是哪段文字（引一小段）。
别贴 id（`h-3f2a…` 这种对用户没意义），要贴就贴页码 + 原文片段。
