# 论文导读

## 什么时候用

- "这篇论文讲了什么？"（用户要概览，不是要某处细节）
- "我该从哪读起？"
- "哪一节讲了实验设置？"
- 用户刚导入论文，想先摸清结构。

## 流程

1. 档案里的**章节结构**是现成的骨架，直接用它，不要重新去检索章节标题。
2. 面向"概览"的回答最多读 3~5 页：摘要页、引言结尾（贡献列表常在那一带）、
   方法节开头、实验节开头。用 `page_markdown_get` 一次读一个区间。
3. 组织成四段：**问题 → 做法 → 证据 → 局限**。每段 1~3 句，不要写成长文。
4. 最后给一句导读建议（比如"想看重放实验直接看第 5 节"），但只在确实从结构里
   看得出这件事时给，别硬编。

## 硬要求

- 概览类回答**也应该带引用**，但不必每句都带 —— 至少"做法"和"证据"两段要有 `[ref]`。
- 不要复述摘要原文（那是它自己的话），用你的话总结；用户能自己看摘要。
- 篇幅控制：概览回答原则上不超过 400 字。用户想看细的会接着问。
