# 证据式论文问答

## 什么时候用这一套

问题是**跨段落的判断**，答案要由多处证据拼出来：

- "这篇论文的核心贡献是什么？"
- "它为什么用随机旋转？"
- "实验证明了什么、还能质疑什么？"
- "它和 XX 方法有什么不同？"

如果问题只是"某一页/某张图里说了什么"，不要走这套长流程 —— 直接读那一页或看那张图。

## 流程

1. **先看档案定方向**：档案里有标题、领域、主要论断、章节结构 —— 它只用来决定往哪儿找。
   凡是要写进回答的判断，仍然要 1 次 `paper_search` + `block_get` 拿到**带编号的正文**
   （档案没有 `[ref]`，按引用硬规则它不是可引用的材料）。
2. **检索**：`paper_search` 是**本论文内的混合检索**（向量召回 + 词法召回 → 融合 → 重排），
   所以 query 要用**论文自己的措辞**（术语、方法名、指标名），不要用口语描述；
   `top_k` 默认 8、上限 12。
   检索方式有三种（`mode`）：`text` 词法——术语 / 指标名 / 引文编号这类**精确词**；
   `rag` 向量——用户用同义说法或概念描述时（"它是怎么避免梯度消失的"）；
   `auto` 默认——两路召回后融合重排。按这个判据选；一次没命中可以**换一种方式**再试一次，
   而不是只换词。
3. **先读检索到的那几块**：拿到 `items` 后按 snippet 挑 **2~4 个最相关的**，用 `block_get(ref)`
   展开 —— 那就是检索到的相似内容本体。只有块自身的上下文不足以判断时，才用
   `page_markdown_get(pages)` 读它所在的页 / 那一小段区间（**别一上来就整页整页读**）。
   命中都不相关（snippet 明显跑题）就换词重搜一次，**最多两次**；两次都不中，如实说没有依据。
4. **表格里的数字**：读页给的是**页级转录**（这篇转录过的话），表格是规整的 Markdown 表格，
   直接照格取值；只有**没转录过**的页才会看到"单元格粘连"的一串（`1645.2945.16` 其实是
   `16 | 45.29 | 45.16`）—— 那种情况 `figure_list(page)` 找 `kind="table"`，再
   `figure_image_get` 看表图。
5. **答**：结论在前，依据在后，每个论断带 `[ref]`。

## 硬要求

- **不要用常识补论文没说的东西**。训练知识里的"这个领域的常规做法"不是这篇论文的内容。
- 论文里的引文编号（`[12]`）是它自己的参考文献，与我们的 `[ref]` **无关**；
  照抄原文时不要动它的方括号编号。
- 涉及数字（加速比、精度、参数量）时必须来自读到的原文，不要四舍五入成"大约"，
  也不要从图里的刻度目测；表格数值见上面的第 4 步（走表图，别抄粘连的正文）。
- 论文有多个版本/附录时以正文为准，附录只在正文明确引用时才用。
