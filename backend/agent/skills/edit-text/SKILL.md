# 编辑页级文本

本技能负责编辑论文页级产物，包括英文转录和中文译文。先读取目标内容并定位修改位置，再实施最小范围的文本修改。默认只处理指定错误、指定表述或术语统一，不顺手润色其他内容。页级产物是阅读器正文、双语导出和检索索引的上游内容，因此必须控制修改范围。完成后逐项说明实际改动；在现有工具支持的情况下提供撤回方式。

页级产物是**事实源**：阅读器正文、双语导出、检索索引都由它派生。
改它 = 改用户的正文，所以这一件事的门槛比"回答问题"高得多。

## 什么时候用

- "这句改成……"、"把全文的 `attention` 统一译成「注意力」"（**逐页**改，一次一处）
- "这句译文不对，应该是……"、"第 5 页那个公式应该是 $d_k$"
- 用户说"你直接帮我改了吧" —— 这是**唯一**的授权来源。
- 若文本像是识别坏了（乱码、符号串位），也走这一套核对再改（流程第 1 步：先看原图）。

**不要**因为"我觉得这样译更好 / 与我的理解不同"就动手：那写在回答里，让用户决定。

## 流程

> 定位与核对阶段的**读**都可以一次给多条：`paper_search(queries=[…])` 一次查几个词、
> `page_markdown_get(pages="4,7")` 一次读几页、`block_get(refs=[…])` 一次展开几块。
> 写也一样：同一串文字用 `op="replace_all"` 一次改完，别一页一次。


1. **先看清哪一侧错了**
   - `page_markdown_get(pages="5")` 一次拿到原文 + 译文，对照着看。
   - 要改的地方散在好几页时**一次取回**：`page_markdown_get(pages="5,7,9")`；
     手上有一批 ref 就 `block_get(refs=[…])` 一次展开 —— 别一页 / 一个 ref 一次调。
   - 怀疑 **OCR** 认错字 → `page_image_get(pages="5", dpi=300)` 看原版面：**以页面图为准**，
     不要用"这样读更通顺"来猜。
   - 怀疑**译文**错 → 以原文为准；术语与档案里的『统一译法』那一段对齐。
2. **拿到逐字文本**：`page_markdown_edit(op="view", page=5, side="original")`
   （`side`：`original` = 英文转录 / `translation` = 中文译文）。返回的是带行号的产物原文 ——
   `find` 必须**逐字**取自它（行号只是路标，不要写进 `find`）。
3. **改一处**：`page_markdown_edit(op="replace", page=5, side="original",
   find="<逐字原文>", replace="<改成>", reason="<为什么>")`。
   删除某处 → `replace=""`。

   **同一串文字在好几页 / 两侧都错**（定理在正文、小节、附录各陈述一遍就是这种）→ 一次改完：
   `page_markdown_edit(op="replace_all", pages="4,7,19", side="both",
   find="<逐字原文>", replace="<改成>", reason="…")`。
   - `pages` 可以 `"4,7"` / `"4-7"` / `"all"`，`side` 多一个 `both`（两侧一起改）；
   - **没读过的页会被跳过**（先读后写仍在）：回执里的 `skipped` 写着原因，读一遍再来；
   - 逐处回报：`done` 是改成的（带行号），`skipped` 是没动的（带原因）——**一处失败不拖累别处**，
     照着 `skipped` 的原因只补那几处，不要整批重来。
4. **改错了**：`op="undo"` 撤回这一页最后一次修改。
5. **报告**：逐条写"第 N 页 · 哪一侧 · 原来 → 现在"，并说明依据（页面图 / 原文）。

## 硬要求

- **先读后写**，且读的是"要改的那一段逐字文本"（`op="view"`）—— 这一页没被读过时会被拒
  （先用 `page_markdown_get` 读它，或 `op="view"` 看一眼）。
- **最小改动**：只改错的那几个字/词。不要顺手润色、不要重排段落。
- **多页同串优先用 `op="replace_all"`**：一页一调最容易漏（漏了就是「改了一半」）；
  但**只在确认是同一处笔误时**用 —— `find` 在别的页可能是另一句话，那就老老实实一页一改。
- 被拒绝时按提示做，别硬试：
  - `没找到 find` → 返回里给了"最像的几行"，照着它改 `find`；
  - `出现 N 次` → 把 `find` 连同前后文一起写，使它整页唯一；
  - `改动会改变段落结构 → 被拒绝` → 改成**同一段内**改字 / 改词（增删段落会被拒）；
    确实要增删段落就如实告诉用户"这一页得重新转录 / 翻译"，并说明你**没有**改动任何东西。
- **没有产物的页改不了**（未转录 / 未翻译的论文走的是解析块）：如实说明，别承诺。
- 产物是被检索索引跟着重建的（改完会自动重建），所以改完的正文在**下一次问答**里也是新的。

## 回答格式

```
已改 1 处：
- 第 5 页 · 英文转录：`d_k` 原来被识别成 `dk` → 已改成 `d_k`（依据第 5 页版面图）。
```
