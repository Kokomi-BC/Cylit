# 译文核对

一次 `page_markdown_get(pages)` 就把**同一页的中英文两份 markdown** 都拿回来 —— 左原文、右译文，
逐句对照。核对的是：有没有漏译、有没有加译、术语是否与档案里的『统一译法』一致。
**不要分两次取**，也不要拿 PDF / 图片当对照源（只有那一页没有解析产物时，才用 `page_image_get`
看原版面兜底）。

只是想读这段中文在讲什么 → `read-text`，那里不核对。

## 什么时候用

- "这句译文对不对？"
- "这段中文怎么这么别扭？"
- 若译文与原文对不上（漏译、多译、公式被改写成文字），也走这一套核对。

## 流程

1. `page_markdown_get(pages)` 一次拿**中英两侧**，对照着看；某一页只有译文没有原文（或相反）时，
   用 `translate_get(pages)` 单独补那一侧，并在报告里点明「这一页缺原文 / 缺译文」。
2. 逐句判断三件事：**有没有漏**（原文一段译文中消失了）、**有没有加**（译文中出现了
   原文没有的断言）、**术语是否与档案里的『统一译法』那一段一致**。
3. 公式、符号、引用编号要**原样保留**：译文里把 `$d_k$` 译成"d k"、把 `[12]` 删掉，
   都算错误。
4. 报告要给**具体位置**（第几页、哪一句），并给出建议改法；不要只说"整体还行"。

## 硬要求

- **译文是派生物，原文才是事实源**。判断对错以原文为准，不要因为译文读起来更顺就认可它。
- 译文里的错误**不要顺手改写成对的再引用**：引用时用能代表原文的表述，并指出译文的问题。
- 用户**明确要求改掉**那处译文时，走 `edit-text`（`page_markdown_edit`）：先读、再改、
  改完逐条报告；没被要求就只在回答里指出问题，**不要动手改**。
- 这一类问题通常**不需要跨库检索**，别去调 `kb_search`。
- 只凭译文无法判断时（原文那一页没解析好），用 `page_image_get` 看原版面。

## 回答格式

结论在前（"译文基本准确，但有两处问题"），然后逐条：位置 → 问题 → 建议。
