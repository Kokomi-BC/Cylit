# 读取阅读器状态

本技能负责获取阅读器的实际状态。调用 reader_state() 读取当前页码、阅读面、视图模式和左侧栏页签，为后续操作确定准确上下文，尤其用于判断高亮与笔记应该落在哪一面。该技能仅读取状态，不改变阅读器状态。工具没有返回的信息不得根据对话内容推测。

## 什么时候用

- 要给"这一段 / 这一页"加高亮或写笔记 → 先 `reader_state()`，再定 `highlight_manage` 的 `side`；
- 要判断该标**原文面**还是**译文面**（`side="en"` / `side="zh"`）；
- 要引用"**读者正在看的那一页**"（"这一页的结论是……"而不是含糊的"后文提到……"）；
- 用户说"标在这里""把这段标一下"但没说页码 / 没说哪一面时。

**不需要**它的时候就别调：纯粹的问答、读正文、总结全篇跟"读者停在哪一面"无关。

## 怎么用（两步）

1. `reader_state()` → 看 `available`、`page`、`page_side`、`note_side`、`view`；
2. 按 `note_side` 传 `highlight_manage(op="create", anchor=…, text=…, side=…)`；
   要给这一处写笔记，就再把这条高亮的 `highlight_id` 交给 `note_manage(op="create")`。

| 字段 | 含义 |
|---|---|
| `available` | 这次请求有没有带阅读状态（`false` = 没有） |
| `page` | 读者停在第几页（`null` = 不知道） |
| `page_side` | `en` 只看原文 / `zh` 只看译文 / `both` 两侧对照 |
| `order` | `en-first` 原文在左 / `zh-first` 译文在左（只影响"左/右"的说法） |
| `view` | `rows` 正文行 / `markdown` / `pdf` |
| `side_tab` | 左栏当前页签 id（`insight` / `highlight` 之类，仅供参考，不要拿它改名次） |
| `visible_pages` | 读者眼前可能还看得见的另几页（可选） |
| `note_side` | **建议落笔的那一面**：`page_side` 是 `en`/`zh` 时就是它，`both` 或未知时是 `null` |
| `page_known` | 页码是否可信（`page` 有值但为 0 时是 `false`） |

**`note_side` 只是建议，不是命令**：要标的那段文字明显属于另一面（比如你抄的是英文原文），
就按文字归属传 `side`，并在回答里说清你标在哪一面、为什么。

## `available=false`：**不要猜**

`available=false` 表示这次请求**没带**阅读状态（老前端、非阅读器入口、或用户从别处发起）。
此时 `page` / `page_side` / `view` 全是空值 —— **绝不许编一个当前页或当前面**：

- 要页码：用 `page_markdown_get` 先定位到那一页，或直接问用户"你现在在第几页"；
- 要判面：按**文字语言**判（现有口径：含中文 → 译文面 `zh`，纯英文原文 → `en`），
  或直接问用户"你现在看的是原文还是译文"。
- 回执里的 `hint` 就是这一句话，照着它做即可。

## `page_side="both"`（对照视图）：按文字归属分面

读者在对照视图里，**两侧都看得见**，所以 `note_side` 给的是 `null` —— 这不是"随便标"，
而是"标哪一面取决于要标的那段文字属于哪一面"：

- 目标是**译文**（中文那几句）→ `side="zh"`；
- 目标是**原文**（英文那几句、公式）→ `side="en"`；
- **不要**同一段两面对半标（用户会多删一半），也**不要**一律退回 `zh`。

## `view` 与"看不看得见"

- `rows`（正文行）：高亮与笔记都画得出来，这是默认落点；
- `markdown` / `pdf`：读者若停在这两个视图上，标在正文行上的东西他**当下看不到**——
  回答里要说明"这条在正文视图里（切回去就能看到）"，不要让他以为你没标上。

## 它只是**只读**的旁证

`reader_state()` **不改变阅读器的任何状态**：不翻页、不换视图、不切页签、不写任何数据。
它读的是"这一次请求带过来的快照"，所以：

- 同一轮里问两次答案一样，**不需要**反复调；
- 读者翻页之后的新一轮会自然拿到新的值——你不需要（也不能）去刷新它；
- 拿到的页码是"读者看到的页"，与 `page_markdown_get` 的页号同一套编号，可以直接混着用。
