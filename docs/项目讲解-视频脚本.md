## 第 0 章 · 一句话定位（30 秒）

**Cylit = 本地优先的「智能论文阅读与知识管理」系统。**

一句话流程：

```
PDF 进  →  解析成结构（IR + Markdown）  →  逐页翻译  →  分块入库
        →  论文精读（理解）  →  阅读器 / 知识库 / 笔记 / 问答
```

三个卖点，讲的时候各举一个例子：

1. **离线可跑**：内置 Mock 模型，没密钥也能走完「解析 → 翻译 → 索引 → 阅读」整条链路。
2. **本地优先**：数据都在 `data/`（论文、页图、IR、译文产物），MySQL / LanceDB 只做索引与元数据。
3. **可验证**：每一步都有自检脚本（后端 35 项、前端上百项、pytest 63 个测试文件），不是"看着能用"。

## 第 2 章 · 后端分层：职责边界（2 分钟）

### 2.1 要点

```
backend/
├─ api/          薄路由：只做参数解析 + 调 service + 套统一信封
├─ services/     ★ 唯一允许碰 repositories / providers / 向量库的层
├─ providers/    模型抽象：generation(openai_compatible / mock) · embedding · reranker
├─ repositories/ mysql · vector(LanceDB) · fs · ir
├─ parsing/      ★ 解析与质保（CLI 与服务端共用，不依赖 services）
├─ core/         config · logging · errors · utils · events
└─ main.py       入口：REST + SSE + 静态资源 + TaskRunner 启停
```

三条要讲的"边界规矩"：

1. **统一响应信封**：所有接口返回 `{data, error, trace_id}`，中间件顺手加
   `x-trace-id` / `x-elapsed-ms` 响应头 —— 出问题能一眼对上日志。
2. **`parsing/` 不依赖 `services/`**：视觉读页这种需要模型的能力，用**钩子注入**
   （`VisionReadFn`），所以 CLI 和服务端能共用同一份解析代码。
3. **模型零硬编码**：业务只写 `model_type`，实现由 Provider 工厂给 —— 换成 Mock 就完全离线。

### 2.2 画面

`backend/` 的目录树 + `main.py` 里路由注册那一段 + 随便打开一个 `api/*.py` 展示"薄"。

## 第 3 章 · 主链路：从导入到能读（这一段是视频主体，8–10 分钟）

按**真实操作顺序**讲，每一步都给出接口、产物、看点。

### 3.1 导入 `POST /papers`

- 算 sha256 → **同一 PDF 重复导入复用已有论文**（不会产生 `-2/-3` 副本）。
- 落 `data/papers/<paper_id>/original.pdf`，写 MySQL `paper` 行。
- 导入弹窗里选**解析引擎**（本地 / 在线 MinerU），以及在线引擎的参数
  （模型 `pipeline`/`vlm`、OCR 语言、强制 OCR、识别公式/表格、页码范围 `1-10` / `2,4-6`）。

### 3.2 解析 `PARSE`（`backend/parsing/pipeline.py`）

```
render_pages(150dpi)                          → pages/*.png
文本层 span / 矢量层路径 / 位图层              → 中间 JSON 落 reports/
自研行聚类 → 双栏阅读顺序 → 段落切分
跨页段落续接 + 页边界拆词修复
公式：候选区域 → 矢量层审计 → LaTeX 候选恢复 → 三重校验 → A/B/C 分级 → 高倍裁图
插图：图注定位 → 图体 bbox（矢量 ∪ 位图）→ 裁剪 → 墨迹/dpi/长宽比体检
质保：一致性约束 + 质量指标
写 IR（ir.sqlite）+ Markdown（md/full.md + blocks.json + 逐页 md）
回写 MySQL：block 定位 / formula / paper 统计
```

**实测（TurboQuant, ICLR 2026, 22 页）**：解析 **3.5 s**；**480 块**
（段落 138 / 标题 38 / 公式 73 / 图注 8 / 插图 5 / 表格 1 / 参考 217）；
公式 **68 条，A 50 / B 17 / C 1 → C 占比 1.5%**（目标 ≤15%）。

### 3.3 逐页翻译（产线 A）—— **一页一次调用，没有第二种粒度**

```
① 页清单：以渲染出的页图为准
② 文档简报（每篇 1 次调用，可关）→ md/translation_brief.json（可人工编辑）
③ 逐页调用：
     input  = 稳定前缀（简报 + 术语表） + 本页页图(150dpi) + 解析器抽出的页内文本
     output = {original_md（忠实转录）, translation_md（逐块对应的中文译文）}
④ 两份 Markdown 按块对齐成行 → 原子写 md/pages.json + SSE page_translated
⑤ 回写 paper.status 与页级进度
```

**实测（真实 DeepSeek 视觉模型）**：22 页 / **22 次调用** / 186.8 s / 成功 22 失败 0 /
**277 行全部 `exact`**；3 页触发过 `max_tokens` 升档（8192→16384→32768→65536）。

### 3.4 分块 + 索引（`cli/pr.py index`）

```
pages.json 的每一行（原子：en=original / zh=translation）
   +  阅读器目录 TOC（宏观边界：节点之间不许因为"长度刚好"被合并）
   +  LLM 语义锚点 breaks（节内边界）
   ↓ 确定性组装（target 软阈值 / hard 硬上限 / 父节引言并入首个子节）
   ↓ 校验层（覆盖一次、顺序不变、不跨节、≤hard、公式表格完整）—— 不通过就退化到行边界
final chunk（正文由行**重新拼装**，绝不重新生成）
→ embedding → LanceDB
```

实测：**128 chunk**，LanceDB 128 条向量。

### 3.5 论文理解 `POST /papers/{id}/understand`

- 两路产物（A 转录 / B 翻译）各自分块后，注入**论文精读**提示词 → 理解产物（`understanding` 表）。
- 引用清单里用短码（如 `来源 Chunk: A012`）回指 chunk；**chunk 既是检索单位，也是引用的基准单位**。

### 3.6 消费端

阅读器三视图 / 知识库 / 笔记 / 学习 / 任务 / 模型 / 设置。

### 3.7 画面

录屏走一遍：导入一篇 PDF → 打开「任务」页看进度与 SSE 实时日志 → 解析完打开阅读器 →
点「翻译」看逐页流式出现 → 知识库页看 chunk → 理解页看精读结果。

## 第 4 章 · 原理亮点（视频的"干货"段落，每点 30–60 秒）

按"反直觉 → 我们怎么做 → 实测结果"三段式讲，效果好。

### 4.1 不信任 PDF 库给的文本块边界

PyMuPDF 会把段落切碎、把展示公式拆成 `h` / `x−Q⁻¹(Q(x))` / `2` 三块。
**我们只把 span 当证据**，自己按**基线聚行**、按**行距基线切段**。

### 4.2 段落判据用 baseline→baseline 的 lead，而不是行 bbox 间距

行内公式的上下标会把行 bbox 撑高，使 gap 变成负值 —— 拿它当判据必然失效。

### 4.3 块 ID 带论文前缀：`turboquantic-p07-b12`

MySQL 的 `block.id` 是全局主键，用 `p07-b12` 会导致**第二篇论文导入时主键冲突**（踩过）。

### 4.4 Markdown 是内容事实源，MySQL 只存定位

避免"三处存正文 → 三处不一致"。阅读器读 `md/blocks.json`（由 Markdown 派生），
既快又与事实源同源。

### 4.5 公式：三重校验 + 分级 + 裁图兜底

矢量层审计（判根号范围 / 分式线 / 上下标）→ LaTeX 候选恢复 → 三重校验 → A/B/C。
C 级不产出 LaTeX，Markdown 用**高倍裁图**兜底，并把 **C 级占比作为质量指标**暴露出来。

### 4.6 页级翻译：「对齐」是天然的，不是算出来的 ★ 最值得讲的一条

同一次调用产出两份互相独立的 Markdown，左右两侧用**同一套纯结构切块**
（空行分段、`$$` 围栏成块、列表项并块）：

- 块数相同 → 按序号一一对应（`align=exact`）；
- 只有块数不同才用 `difflib` 做一次序列对齐（`align=structure`，块不丢）。

**没有锚点、没有保序 DP、没有回退补译、没有严格校验档** —— 旧版的 `page_aligner`、
块级回退、三层缓存全部删除。实测 277 行 **100% exact**。

### 4.7 前缀缓存靠"字节级稳定的前缀"

文档简报与术语表在整篇内不变、且放在 prompt **最前面**；
**严禁混入时间戳 / 页码 / 统计量**，否则 provider 的前缀缓存必然不命中。

### 4.8 扫描件（影印 PDF）走同一条链路

文本层为空时页内文本只是空参考，模型完全依据页图转录 + 翻译：

- **判定**：该页文本层字符 **< 40 且含整页图像**（不能用 `== 0`，影印件常带零星 OCR 残渣）；
- **读页另渲 200dpi**（150dpi 对小字号上下标偏糊）；
- **约定**：只转录不翻译，看不清写 `[?]`，**不许靠语义猜**；页眉页脚与页码不转录；
- 扫描页**不跑**公式候选与插图检测（整页图会被误判成一张巨型插图）。

实测：2 页纯图像 PDF → 识别 13 s（≈4.9k 字符/页）→ 翻译 36 s，2/2 成功。

### 4.9 两条解析引擎共用一套产物

在线解析（MinerU）不是"另一个阅读器"，它把 `content_list.json` 归一化成**同一份 `ParseResult`**，
并把 MinerU 的 bbox 当**精确来源直接采用**。于是换引擎只影响导入/重解析，**下游一行都不用改**。

### 4.10 任务系统：租约 + 心跳 + 断点续跑

MySQL 任务表 + 租约 + 心跳 + 断点续跑 + 暂停/取消（**在页边界生效**）+ 过期租约回收。
幂等靠"已有页级产物与 `cursor.done_pages` 里的页不再调用模型"。

### 4.11 自适应并发（诚实说明现状）

调度器本身有：动态窗口 N∈[1,8] / 429 退避（遵守 `Retry-After`）/ 连续成功回升 / 连续失败熔断 /
token 与耗时记录 / 并发时间线。

**但页级翻译现在固定串行（窗口=1）**，这套能力只剩 `python cli/pr.py bench` 的对照实验在用 ——
做视频时**要主动说明这一点**，比被人问出来好。

### 4.12 Agent 服务：独立进程 + 白名单工具

```
浏览器 → POST /cylit/api/agent/ask (SSE)
       → 主后端 :8710（鉴权 / 会话读写 / SSE 字节级转发，不解释事件）
       → Agent 服务 :8711（pydantic-ai + skills/）
       → 14 个工具（11 读 + 3 写）回调主后端 /api/v1/*
```

三条边界原则（这是设计感最强的一段）：

1. **Agent 不直连 MySQL / LanceDB / 产物目录**，只经主后端 HTTP 拿数据 ——
   "什么能被 agent 看到"只有一个审批点；
2. **Agent 不持有模型密钥**：模型配置由主后端下发，**设置页仍是密钥唯一入口**；
3. **主后端不解释 agent 事件**，只做字节转发。

工具面的原则：每个工具一个 pydantic 入参模型 + 一个**瘦投影**返回；
`paper_id` **由宿主覆写**（模型改不了）；工具名用动宾结构，描述里写"什么时候用"。

### 4.13 引用链四段（缺一段就"点不动"或"泄漏内部 id"）

工具 → 引用短码 → 前端定位 → 回跳原文。做演示时点一下引用，比讲十句有用。

## 第 5 章 · 前端（3 分钟）

### 5.1 要点

- **多标签页外壳**：顶栏是标签条（`components/TabBar.vue`），导航入口在首页；
  `stores/tabs.ts` 管标签，`stores/scrollMemory.ts` 记每个标签**各自的滚动位置**。
- **十个路由**：`/home`、`/library`、`/reader/:paperId`、`/understand/:paperId`、
  `/knowledge`、`/study`、`/notes`、`/models`、`/tasks`、`/settings`。
- **阅读器三视图**：原文文本 / 原 PDF（pdf.js，可选中复制）/ 译文 / 对照；
  **单一滚动容器**，没有联动脚本；窄屏（<1100px）自动上下堆叠。
- **整屏布局**：滚动只发生在正文栏内（`grid-template-rows: auto minmax(0,1fr)` +
  `min-*: 0`），整页不滚动。
- **状态是服务端权威**：`view_mode / pair_order / last_block_id / scroll_ratio` 存服务端，
  刷新和换设备都还原；`?view=&order=&left=&row=` 可深链。
- **样式**：WinUI 3 设计令牌（`styles/tokens.css`）+ `base.css` + 组件 scoped 样式；
  主题皮肤在 `styles/themes/*.css`，由 `theme/registry.ts` 注册；**图标一律内联 SVG**（无 emoji）。
- **SSE**：`composables/useEventStream.ts` 断线自动降级轮询（`?nosse=1` 可强制降级）。

### 5.2 画面

录屏：首页 → 论文库 → 打开阅读器切三种视图（`1/2/3`）→ 换左右（`o`）→ 切原 PDF（`p`）→
`/` 搜索 → 划词解释 → 右栏笔记 → 设置页换主题。
